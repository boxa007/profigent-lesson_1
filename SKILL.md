# Company Context Model

Фундаментальний скіл. Один запуск = структура папок + заповнена контекстна модель компанії.

## Коли запускати

Учасник програми відкрив новий Claude Code проект під LinkedIn і потребує:
- Структуру папок для бізнес-контексту
- Один документ що "знає" про компанію все потрібне для AI
- Базу даних що йтиме входом для Промптів 1/2/3 і всіх інших скілів

**Запускається ПЕРШИМ** перед будь-яким іншим LinkedIn-скілом.

## Що питаємо ПЕРЕД стартом

Підтверди з користувачем у одному повідомленні:

1. **Корінь проекту** — де створювати структуру. Default: поточна робоча директорія. Якщо хочуть інше місце — нехай дадуть абсолютний шлях.
2. **Slug компанії** — латиницею, без пробілів (наприклад `profigent`, `bricknest`, `acme-services`). Використовується як назва кореневої папки.
3. **Що уже є** — будь-що з: URL сайту, LinkedIn URL засновника, intro-документ, пітч-дек, нотатки. Нічого = теж OK, пройдемось чисто через інтерв'ю.

Тоді стартуй.

## Структура яка створюється

```
[slug]/
├── _context-model.md          ← головний документ-синтез (готовий вхід для всіх промптів)
├── 01-positioning/
│   ├── who-we-are.md          ← категорія, місія, проти кого ми
│   ├── what-we-sell.md        ← оффер, ціни, моделі
│   └── how-we-different.md    ← диференціація vs конкуренти
├── 02-icp/
│   ├── who-is-our-client.md   ← роль, розмір, регіон, стадія
│   ├── pains.md               ← топ-3 болі ICP
│   └── triggers.md            ← гарячі сигнали (hire, fund, post, etc.)
├── 03-proof/
│   ├── cases.md               ← кейси з конкретними цифрами
│   ├── metrics.md             ← середні метрики (reply rate, deal size, тощо)
│   └── testimonials.md        ← відгуки клієнтів
├── 04-voice/
│   ├── tone.md                ← як ми говоримо (формальний/casual/прямий)
│   ├── sticker-phrases.md     ← 5 фраз які повторюємо у кожному пості
│   └── forbidden-words.md     ← слова яких уникаємо (AI-tells)
├── 05-content/
│   ├── pillars.md             ← 3-4 тематичні опори (заповнимо на уроці 2)
│   ├── topics.md              ← банк ідей для контенту
│   └── published/             ← архів опублікованих постів з метриками
└── _inputs/                    ← сирі матеріали (PDF, скріншоти, транскрипти)
```

## Інтерв'ю — 15 питань у 5 батчах

Запитуй **батчами по 3-4 питання**, не по одному. Після кожного батчу записуй у відповідні файли (`01-positioning/`, `02-icp/`, тощо). Якщо учасник прикріпив сайт / LinkedIn / документ — спочатку парс що можеш, потім питай ТІЛЬКИ прогалини.

### Батч 1 — Хто ми (3 питання)

1. **Назва компанії + 1-реченняовий опис.** Що ви робите простими словами?
2. **Категорія в якій конкуруєте.** "B2B outbound", "fractional CTO", "AI-driven lead-gen", "design systems consulting" — щось таке. Не "marketing agency".
3. **Проти кого ми (enemy).** Яка погана практика / шумний тренд / стереотип галузі — ви проти? Одне речення.

→ Записати у `01-positioning/who-we-are.md`

### Батч 2 — Що продаємо (3 питання)

4. **Що продаємо.** Послуги, продукти, пакети. Якщо є кілька — назви топ-3.
5. **Цінові точки.** За яку ціну? Діапазон ОК. Якщо custom — мінімальний контракт.
6. **Модель.** Project-based / retainer / hourly / subscription / hybrid?

→ Записати у `01-positioning/what-we-sell.md`

### Батч 3 — Ідеальний клієнт (4 питання)

7. **Хто ваш ідеальний клієнт?** Роль (founder / CTO / VP marketing), розмір компанії (employees, ARR), регіон, стадія (Seed / Series A / scaling / enterprise).
8. **3 основні болі цього клієнта зараз.** Конкретно. Не "вони хочуть зростати" — "у них reply rate 2%" або "вони шукають заміну SDR команді".
9. **Які гарячі сигнали** показують що клієнт зараз дозрів? (наприклад: компанія наймає SDR, фаундер опублікував пост про лідогенерацію, нещодавно raised funding)
10. **З ким вас порівнюють?** 2-3 конкретні конкуренти або тип компаній.

→ Записати у `02-icp/who-is-our-client.md`, `02-icp/pains.md`, `02-icp/triggers.md`

### Батч 4 — Диференціація та докази (3 питання)

11. **Ваш унікальний механізм.** Чим ви відрізняєтесь — не загально ("ми краще"), а конкретно ("ми використовуємо сигнали замість списків", "ми пишемо у голосі клієнта а не generic LinkedIn"). Одне речення.
12. **Найвражаючіший кейс з цифрами.** Клієнт + до/після + термін + механіка. Якщо є кілька — топ-1.
13. **Що ви робите чого конкуренти НЕ роблять?** 1-3 пункти.

→ Записати у `01-positioning/how-we-different.md`, `03-proof/cases.md`

### Батч 5 — Голос (2 питання)

14. **Як ви говорите про свою роботу?** Формально / casual / прямо / консультативно / провокаційно? Який тон у клієнтських дзвінках?
15. **5 фраз / термінів які ви постійно повторюєте.** Це ваші бренд-стикери — будемо вставляти у пости для AI-search індексації.

→ Записати у `04-voice/tone.md`, `04-voice/sticker-phrases.md`

### Бонус-крок: заборонені слова

Прочитати топ-20 AI-tells і питати: "З цих слів — які ви точно не використовуєте? Які — використовуєте часто, треба прибрати?"

Список AI-tells:
leverage, synergy, passionate, thrilled, humbled, delve into, in today's landscape, transformative, innovative, cutting-edge, game-changing, revolutionize, ecosystem, unlock, supercharge, seamless, dive into, at the end of the day, I'm excited to share, I'm humbled to announce

→ Записати у `04-voice/forbidden-words.md`

## Синтез у _context-model.md

Після збору всіх відповідей — згенеруй головний документ за шаблоном:
`templates/context-model-template.md`

Документ має містити:
1. **Identity** — назва, категорія, enemy (1 параграф)
2. **Offer** — що, кому, за яку ціну (3-5 буллетів)
3. **ICP** — повний портрет (роль, розмір, регіон, стадія, болі, тригери)
4. **Differentiation** — унікальний механізм + 3 пункти що конкуренти НЕ роблять
5. **Proof** — топ-3 кейси з конкретними цифрами
6. **Voice** — тон + 5 стикер-фраз + список заборонених слів
7. **Goals** — 90-день LinkedIn ціль + метрика успіху

Цей документ можна паст у будь-який AI-промпт як CONTEXT блок.

```

Структура: ./[slug]/
Головний документ: ./[slug]/_context-model.md  ← це ваш робочий контекст

ЩО ДАЛІ:
1. Прочитайте _context-model.md і відкоригуйте якщо щось не так
2. Запустіть Промпт 1 — Аналіз сайту (/content-brief-setup)
   → результат збагатить контекстну модель
3. Запустіть Промпт 2 — Аудит профілю (/linkedin-profile-audit)
   → візьме _context-model.md як вхід, видасть 5 заголовків + перепис About
4. На уроці 2: Промпт 3 — Контент-стратегія (/strategy-plan)
   → використає всю модель + видасть план на 12 постів × 4 тижні

ВАЖЛИВО: контекстну модель оновлюйте ЩОТИЖНЯ — додавайте нові кейси, метрики, інсайти.
Чим багатша модель → тим точніше AI пише як ВИ, не як generic ChatGPT.
```

## Hard rules

1. **15 питань максимум.** Не розтягуй на 30 — учасник кине.
2. **Батчі по 3-4.** Не по одному (виглядає як допит). Не по 8 (важко відповідати).
3. **Парс що можеш з URL/документів ДО питань.** Якщо є сайт — не питай "що продаєте", вже бачив.
4. **Конкретика обовʼязкова.** Якщо відповідь "ми краще за конкурентів" — переспитай: "Чим саме? Дай 1 приклад."
5. **Файли — markdown, не JSON.** Учасник буде редагувати руками.
6. **Українською.** Усе ОК. Англійська тільки якщо учасник сам пише англійською.
